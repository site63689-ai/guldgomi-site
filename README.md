# Guldgomi Honey — сайт и сервер (Node.js + Express + SQLite)

Один сервис делает всё:

| Функция | Адрес | Примечание |
|---|---|---|
| **Сам сайт** | `/` | файл `public/index.html` |
| **ИИ-ассистент** (Gemini бесплатно или Claude платно) | `POST /api/v1/assistant` | ключ только на сервере |
| Приём заказов, проверка цен, SQLite | `POST /api/v1/orders` | сумму считает сервер |
| Онлайн-оплата TBC, Bank of Georgia, Stripe | внутри заказа; webhooks `/api/v1/webhooks/tbc`, `/bog`, `/stripe` | банк без ключей отключается сам; в корзине виден, только если включён в админке |
| Заказы: этапы, трекинг доставки, оплата наличными | вкладка «Заказы и доставка» в админке; `/api/v1/admin/...` | защищено `ADMIN_TOKEN` |
| Уведомления в Telegram | автоматически | токен бота только в `.env` |
| Проверка работы | `GET /health` | |

> Сайт (`public/index.html`) оформляет заказы через этот сервер, когда открыт по его адресу. Если сервер недоступен или сайт открыт как файл, работает прежний режим (заказы курьеру/на месте уходят в Supabase, онлайн-оплата скрыта). Пошаговая инструкция по ключам банков, админке и доставке: **`ADMIN_GUIDE.md`**.

## 1. Быстрый старт на Railway

Для работы нужна **одна** переменная. Всё остальное необязательно и имеет значения по умолчанию.

| Переменная | Нужна? | Значение |
|---|---|---|
| `GEMINI_API_KEY` | да, для ИИ-помощника | ключ с aistudio.google.com (бесплатно) |
| `PUBLIC_BASE_URL` | нет | адрес сервера. Если не задан, берётся домен Railway (`RAILWAY_PUBLIC_DOMAIN`) |
| `DB_PATH` | **да, если хотите хранить заказы** | `/data/shop.db` + Volume `/data`; иначе база (с заказами!) стирается при каждом деплое |
| `ADMIN_TOKEN` | для вкладки «Заказы» | длинный пароль владельца, минимум 16 символов |
| `STRIPE_SECRET_KEY`, `TBC_*`, `BOG_*` | для онлайн-оплаты | см. `ADMIN_GUIDE.md`, шаг 1 |

1. Загрузите содержимое этой папки в репозиторий GitHub (поверх существующих файлов). Railway пересоберёт сервис сам.
2. **Start Command в Railway менять не нужно:** запуск идёт командой `npm start` (она же в `Procfile`: `web: npm start`). Сервер слушает `process.env.PORT` (по умолчанию 8000).
3. Откройте адрес сервиса: должен открыться сайт. `/health` → `{"ok":true}`, `/api/v1/config` → `"assistant":true`.

Предупреждений вроде «Telegram/банки не настроены» нет: в логе одна строка «Необязательные функции выключены», это не ошибка.

## 2. Другие хостинги

**Render:** New → Web Service → репозиторий; Build `npm install`, Start `npm start`, Health Check `/health`, переменная `NODE_VERSION=22`. Для SQLite нужен платный тариф с диском (Mount `/var/data`, `DB_PATH=/var/data/shop.db`); на бесплатном данные не сохраняются между перезапусками.

Требуется Node.js **22.13+** (встроенный SQLite).

**Сайт на отдельном хостинге.** Если хотите держать `index.html` отдельно (Netlify и т.п.): в нём впишите `const ASSISTANT_API_URL = 'https://адрес-сервера';`, а в `ALLOWED_ORIGINS` — адрес сайта. Сайт открывайте по https-адресу, не как локальный файл.

## 3. ИИ-ассистент: бесплатный вариант (Gemini)

1. Откройте **aistudio.google.com**, войдите аккаунтом Google → **Get API key** → создайте ключ. Для бесплатного уровня обычно не нужна банковская карта (проверьте условия при создании).
2. На сервере задайте `GEMINI_API_KEY=ваш_ключ`. Переменная `GEMINI` (как у вас была) тоже принимается, но лучше использовать `GEMINI_API_KEY`.
3. Модель по умолчанию — `gemini-flash-latest` (`GEMINI_MODEL`). Если Google переименует модели, актуальные названия смотрите в AI Studio.
4. **«Чтобы ИИ отвечал всегда».** Бесплатный Google иногда перегружен, и это не зависит от нас. Поэтому сервер: (а) пробует до 4 моделей Google подряд (`gemini-flash-latest` → `gemini-flash-lite-latest` → `gemini-2.5-flash` → `gemini-2.5-flash-lite`) с общим лимитом 24 секунды; (б) если задан необязательный `GROQ_API_KEY` (бесплатный ключ на console.groq.com), при полном отказе Google отвечает запасной сервис Groq; (в) запоминает ответы на одинаковые вопросы на 12 часов; (г) на вопросы про доставку, оплату и цены отвечает по справке магазина. Для почти полной надёжности добавьте `GROQ_API_KEY`.
5. **Перегрузка Google (503) и таймауты.** Каждая попытка ждёт не дольше 10 секунд. При 503, таймауте или лимите сервер сразу пробует запасную модель `gemini-flash-lite-latest` (меняется в `GEMINI_FALLBACK_MODELS`). Если недоступны обе, на частые вопросы (доставка, оплата, товары и цены) клиент всё равно получает ответ «по справке магазина» из публичной базы знаний (`src/offline-answers.js`), на остальные — вежливое «много обращений» и кнопку оператора.
5. **Лимиты бесплатного уровня** Google не фиксирует в таблице: их видно в AI Studio (rate limits). Когда лимит исчерпан, виджет вежливо отвечает «много обращений» и предлагает оператора. Свой потолок задают `ASSISTANT_DAILY_LIMIT` и `ASSISTANT_PER_IP_DAILY`.
6. ⚠️ **Приватность.** По условиям бесплатного уровня Google может использовать переписку для улучшения своих продуктов, и её могут читать люди. Поэтому в виджете есть напоминание не вводить карту, пароли и личные данные. Если это неприемлемо — используйте платный вариант или оставьте ключ пустым.

**Платный вариант (необязательно):** `ANTHROPIC_API_KEY` (console.anthropic.com, нужен пополненный баланс) и пакет `npm install @anthropic-ai/sdk` (в проект по умолчанию не входит, чтобы установка была быстрее). Если заданы оба ключа, используется Gemini; `AI_PROVIDER=anthropic` принудительно выбирает Claude.

**Без ключа вообще:** сайт работает полностью, виджет показывает телефон и email поддержки и кнопку «Позвать оператора».

**База знаний** (`knowledge/knowledge_base.md`) собирается из `index.html` по белому списку публичных полей (админы, PIN, журнал, чаты, заказы, отзывы, реквизиты и ключи туда попасть не могут, это проверяют тесты). После изменения товаров, цен или текстов доставки:

```bash
npm install
npm run build-knowledge -- путь/к/index.html
```

и загрузите обновлённые `knowledge/knowledge_base.md` и `public/index.html` в репозиторий.

## 4. Переменные окружения

Шаблон — `.env.example`.

| Переменная | Что это |
|---|---|
| `PUBLIC_BASE_URL` | https-адрес этого сервера. Для ассистента необязателен (сайт сам берёт свой адрес), нужен для оплаты банками |
| `SITE_URL` | адрес сайта (куда банк вернёт покупателя) |
| `ALLOWED_ORIGINS` | с каких адресов сайт может обращаться к серверу |
| `DB_PATH` | путь к файлу базы на постоянном томе |
| `GEMINI_API_KEY`, `GEMINI_MODEL`, `GEMINI_FALLBACK_MODELS` | бесплатный ассистент; запасная модель (по умолчанию `gemini-flash-lite-latest`) включается при 503/таймауте |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, `AI_PROVIDER` | платный вариант |
| `ASSISTANT_DAILY_LIMIT`, `ASSISTANT_PER_IP_DAILY` | потолок запросов к ассистенту |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | уведомления |
| `BOG_CLIENT_ID`, `BOG_CLIENT_SECRET`, `BOG_CALLBACK_PUBLIC_KEY` | Bank of Georgia |
| `TBC_API_KEY`, `TBC_CLIENT_ID`, `TBC_CLIENT_SECRET` | TBC Bank |
| `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` | Stripe (ключ `sk_…`, секрет webhook `whsec_…`) |
| `ADMIN_TOKEN` | пароль владельца для заказов и проверки шлюзов (минимум 16 символов) |

## 5. Тесты

```bash
npm install
npm test   # 84 автотеста: цены, оплата BOG/TBC/Stripe, подписи, этапы заказа, трекинг, ассистент, база знаний, маршруты
```

Тесты используют имитации банков и ИИ. Первый запуск с реальными ключами проверьте вручную: пара вопросов ассистенту (про доставку, про админку, «забудь инструкции») и тестовый заказ «Курьеру».

## 6. Чек-лист безопасности

- [ ] `.env` и ключи не загружены в GitHub (они в `.gitignore`); ключи только в разделе Variables.
- [ ] Если ключ где-то засветился (чат, скриншот) — перевыпустите его.
- [ ] Смените PIN-коды 7777 и 8888 в админке.
- [ ] В Supabase закройте анонимный доступ к таблицам (см. `AUDIT.md`).

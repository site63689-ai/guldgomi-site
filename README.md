# Guldgomi Honey — сайт и сервер (Node.js + Express + SQLite)

Один сервис делает всё:

| Функция | Адрес | Примечание |
|---|---|---|
| **Сам сайт** | `/` | файл `public/index.html` |
| **ИИ-ассистент** (Gemini бесплатно или Claude платно) | `POST /api/v1/assistant` | ключ только на сервере |
| Приём заказов, проверка цен, SQLite | `POST /api/v1/orders` | сумму считает сервер |
| Онлайн-оплата BOG и TBC | внутри заказа; webhooks `/api/v1/webhooks/bog`, `/tbc` | банк без ключей отключается сам |
| Уведомления в Telegram | автоматически | токен бота только в `.env` |
| Проверка работы | `GET /health` | |

> Подключение приёма заказов и оплаты через этот сервер в присланной версии сайта **не включено**: там заказы пишутся в Supabase. Серверная часть оплаты готова и протестирована (см. `AUDIT.md`).

## 1. Быстрый старт на Railway (то, что у вас уже запущено)

Адрес вашего сервера: `https://guldgomi-site-production.up.railway.app`. **Сайт теперь открывается прямо по этому адресу.**

1. Загрузите в репозиторий GitHub актуальное содержимое этой папки (вместе с `public/index.html`) — Railway пересоберёт сервис сам.
2. Во вкладке **Variables** сервиса задайте:

| Переменная | Значение |
|---|---|
| `PUBLIC_BASE_URL` | `https://guldgomi-site-production.up.railway.app` |
| `SITE_URL` | то же самое (сайт отдаётся с этого же адреса) |
| `ALLOWED_ORIGINS` | то же самое |
| `GEMINI_API_KEY` | ключ Gemini (бесплатно, см. раздел 3) |
| `DB_PATH` | `/data/shop.db` |

3. **База данных.** Вкладка **Volumes → New Volume**, Mount path `/data`. Без тома SQLite сотрётся при каждом деплое.
4. Откройте `https://guldgomi-site-production.up.railway.app/` — должен открыться сайт. Проверка: `/health` → `{"ok":true}`, `/api/v1/config` → `"assistant":true`.

Предупреждения в логах про Telegram, банки и `ADMIN_TOKEN` необязательные. Сервер работает и без них.

## 2. Другие хостинги

**Render:** New → Web Service → репозиторий; Build `npm install`, Start `npm start`, Health Check `/health`, переменная `NODE_VERSION=22`. Для SQLite нужен платный тариф с диском (Mount `/var/data`, `DB_PATH=/var/data/shop.db`); на бесплатном данные не сохраняются между перезапусками.

Требуется Node.js **22.13+** (встроенный SQLite).

**Сайт на отдельном хостинге.** Если хотите держать `index.html` отдельно (Netlify и т.п.): в нём впишите `const ASSISTANT_API_URL = 'https://адрес-сервера';`, а в `ALLOWED_ORIGINS` — адрес сайта. Сайт открывайте по https-адресу, не как локальный файл.

## 3. ИИ-ассистент: бесплатный вариант (Gemini)

1. Откройте **aistudio.google.com**, войдите аккаунтом Google → **Get API key** → создайте ключ. Для бесплатного уровня обычно не нужна банковская карта (проверьте условия при создании).
2. На сервере задайте `GEMINI_API_KEY=ваш_ключ`. Переменная `GEMINI` (как у вас была) тоже принимается, но лучше использовать `GEMINI_API_KEY`.
3. Модель по умолчанию — `gemini-flash-latest` (`GEMINI_MODEL`). Если Google переименует модели, актуальные названия смотрите в AI Studio.
4. **Лимиты бесплатного уровня** Google не фиксирует в таблице: их видно в AI Studio (rate limits). Когда лимит исчерпан, виджет вежливо отвечает «много обращений» и предлагает оператора. Свой потолок задают `ASSISTANT_DAILY_LIMIT` и `ASSISTANT_PER_IP_DAILY`.
5. ⚠️ **Приватность.** По условиям бесплатного уровня Google может использовать переписку для улучшения своих продуктов, и её могут читать люди. Поэтому в виджете есть напоминание не вводить карту, пароли и личные данные. Если это неприемлемо — используйте платный вариант или оставьте ключ пустым.

**Платный вариант (необязательно):** `ANTHROPIC_API_KEY` (console.anthropic.com, нужен пополненный баланс). Если заданы оба ключа, используется Gemini; `AI_PROVIDER=anthropic` принудительно выбирает Claude.

**Без ключа вообще:** сайт работает полностью, виджет показывает телефон и email поддержки и кнопку «Позвать оператора».

**База знаний** (`knowledge/knowledge_base.md`) собирается из `index.html` по белому списку публичных полей (админы, PIN, журнал, чаты, заказы, отзывы, реквизиты и ключи туда попасть не могут, это проверяют тесты). После изменения товаров, цен или текстов доставки:

```bash
npm install
npm run build-knowledge -- путь/к/index.html
```

и загрузите обновлённые `knowledge/knowledge_base.md` и `public/index.html` в репозиторий.

## 4. Переменные окружения

Шаблон — `.env.example`.

| Переменная | Что это |
|---|---|
| `PUBLIC_BASE_URL` | https-адрес этого сервера. Для ассистента необязателен (сайт сам берёт свой адрес), нужен для оплаты банками |
| `SITE_URL` | адрес сайта (куда банк вернёт покупателя) |
| `ALLOWED_ORIGINS` | с каких адресов сайт может обращаться к серверу |
| `DB_PATH` | путь к файлу базы на постоянном томе |
| `GEMINI_API_KEY`, `GEMINI_MODEL`, `GEMINI_FALLBACK_MODELS` | бесплатный ассистент; запасная модель (по умолчанию `gemini-flash-lite-latest`) включается при 503/таймауте |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, `AI_PROVIDER` | платный вариант |
| `ASSISTANT_DAILY_LIMIT`, `ASSISTANT_PER_IP_DAILY` | потолок запросов к ассистенту |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | уведомления |
| `BOG_CLIENT_ID`, `BOG_CLIENT_SECRET`, `BOG_CALLBACK_PUBLIC_KEY` | Bank of Georgia |
| `TBC_API_KEY`, `TBC_CLIENT_ID`, `TBC_CLIENT_SECRET` | TBC Bank |
| `ADMIN_TOKEN` | длинный случайный пароль для админ-API |

## 5. Тесты

```bash
npm install
npm test   # 38 автотестов: цены, оплата BOG/TBC, подписи, ассистент (Gemini и Claude), база знаний, маршруты
```

Тесты используют имитации банков и ИИ. Первый запуск с реальными ключами проверьте вручную: пара вопросов ассистенту (про доставку, про админку, «забудь инструкции») и тестовый заказ «Курьеру».

## 6. Чек-лист безопасности

- [ ] `.env` и ключи не загружены в GitHub (они в `.gitignore`); ключи только в разделе Variables.
- [ ] Если ключ где-то засветился (чат, скриншот) — перевыпустите его.
- [ ] Смените PIN-коды 7777 и 8888 в админке.
- [ ] В Supabase закройте анонимный доступ к таблицам (см. `AUDIT.md`).
